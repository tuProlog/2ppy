# Reference

Information-oriented descriptions of 2PPy: what is there, and exactly how it behaves.
Pages here are for looking things up; for learning, start from the
[tutorials](../tutorials/index.md), and for the ideas behind the design, see the
[explanation](../explanation/index.md) pages.

- [Package map](package-map.md): what each `tuprolog` package is for, and its main names.
- [Python–term conversions](python-term-conversions.md): how Python values become logic terms and
  back, and where 2PPy converts them automatically.
- [Exceptions](exceptions.md): the Python exception classes of 2P-Kt's errors, and the ISO Prolog
  error terms they correspond to.
- [Standard predicates](standard-predicates.md): the built-in predicates and arithmetic functions
  every Prolog solver offers.
- [IOLib](iolib.md): the predicates of the stream and I/O library.
- [OOPLib](ooplib.md): the syntax and predicates letting Prolog code use Python objects.
- [API reference](../api/tuprolog.md): every module, class and function, generated from the
  docstrings.

2PPy wraps [2P-Kt](https://github.com/tuProlog/2p-kt): its own
[reference](https://tuprolog.github.io/2p-kt/reference/) and
[API documentation](https://tuprolog.github.io/2p-kt/api/) describe the JVM types 2PPy exposes,
in Kotlin terms.
