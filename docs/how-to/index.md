# How-to guides

How-to guides are recipes: each shows how to accomplish one task, assuming you know the basics
(see the [tutorials](../tutorials/index.md) otherwise).

- [Build and parse terms](build-and-parse-terms.md): create terms from Python values or Prolog text,
  inspect them, and print them back.
- [Query solvers](query-solvers.md): configure solvers and queries (knowledge bases, limits,
  timeouts, laziness, flags, operators).
- [Define predicates in Python](define-predicates-in-python.md): extend solvers with predicates and
  arithmetic functions written in Python, packed into libraries.
- [Use Python objects from Prolog](use-python-objects-from-prolog.md): create Python objects, call
  their methods and read their attributes from Prolog code, with OOPLib.
- [Read and write streams](read-and-write-streams.md): load programs from files, and connect
  solvers' input and output to Python streams; use ISO Prolog stream predicates with IOLib.
- [Handle errors](handle-errors.md): catch logic errors in Prolog and in Python.
- [Run probabilistic programs](run-probabilistic-programs.md): compute the probability of
  queries with ProbLog.
- [Use the REPL](use-the-repl.md): experiment with Prolog interactively.
- [Contribute](contribute.md): set up a development environment, run the checks, write
  documentation, and release.
